Superstore Sales Dashboard | Power BI

 Overview

The **Superstore Sales Dashboard** is an interactive Business Intelligence project developed using **Microsoft Power BI**. It analyzes sales performance across different regions, categories, customer segments, and time periods to help stakeholders make informed business decisions.

The dashboard combines key performance indicators (KPIs), interactive filters, and dynamic visualizations to provide a comprehensive view of business performance.

---

 Objectives

* Analyze overall sales and profit performance.
* Monitor business growth through interactive KPIs.
* Identify top-performing regions and product categories.
* Compare customer segments and shipping modes.
* Visualize sales trends over time.
* Enable users to explore data using interactive slicers.

 Tools & Technologies

 Dataset

The dashboard is built using the **Superstore Sales Dataset**, which includes information such as:

* Order Date
* Sales
* Profit
* Quantity
* Discount
* Customer Name
* Category
* Sub-Category
* Region
* State
* Segment
* Ship Mode

 Dashboard Features

 KPI Cards

* 💰 Total Sales
* 📈 Total Profit
* 📦 Total Orders
* 👥 Total Customers
* 📊 Profit Margin

Interactive Visualizations

* Monthly Sales Trend (Line Chart)
* Sales by Category (Column Chart)
* Profit by Region (Bar Chart)
* Sales by Customer Segment (Donut Chart)
* Sales by Sub-Category (Treemap)
* Sales by State (Map)
* Product Performance Table

 Interactive Slicers

* Year
* Month
* Region
* Category
* Segment
* Ship Mode
